# Sky V Cosmetics · Sitio web

Es la tienda virtual de cosméticos de mi emprendimiento **Sky V Cosmetics**, ahora full-stack. Es el mismo sitio de la Entrega 1 (inicio con las marcas, catálogo y formulario), reconstruido en Next.js con Tailwind, conectado a mi propia API, con registro, inicio de sesión, pedidos guardados en base de datos y un panel de administración.

- **Sitio en producción:** https://skyv-web.vercel.app
